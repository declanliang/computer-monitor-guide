# Blog Taxonomy

## Purpose

The blog exists for time-sensitive content that should not live in the evergreen guide or recommendation hubs.

## Primary Content Types

- `reviews`: single-product reviews for named monitor models
- `comparisons`: head-to-head or format-to-format decision articles
- `buying-news`: launches, promotions, and market updates that can age quickly

## URL and Metadata Rules

- Every post must use one of the defined tags in [blog/tags.yml](C:/Users/liang/Documents/Projects/display_guide/blog/tags.yml).
- Review posts should include the model name in the title and slug.
- Comparison posts should use `x-vs-y` style slugs.
- Buying-news posts should include a concrete date in the filename when timeliness matters.

## Linking Rules

- Reviews must link to at least one recommendation hub and one guide page.
- Comparisons must link to the most relevant fundamentals or advanced explainer.
- Buying-news posts should link to the relevant recommendation roundup when it exists.
